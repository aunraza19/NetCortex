# Detector runtime integration progress

Implemented the B-owned `netcortex-detector-worker --artifact PATH` launcher and async `run_worker()` API. It configures the validated detector artifact in a background thread before lazily importing and awaiting the unchanged Temporal worker in the same process. Setup errors fail startup before worker execution; no core worker or shared Settings files were changed.

Forecast inference now batches the three normal VALIDATION density references into one extension call. Raw metric models are cached by training fingerprint and protected by fixed striped locks; independent targets run with at most eight concurrent workers. The TabPFN backend opts into overlapping main forecasts, unchanged walk-forward checks, cause, and anomaly inference. Its walk-forward provider batches identical training fingerprints across the three prior-only contexts while retaining per-query target-time validation. Custom/fixture backends remain sequential unless they opt in. Each `forecasts()` call has a 90-second wall-time deadline; timeout cancels queued work and drains active calls under their configured finite timeouts before failing without partial forecasts. It is not an end-to-end detect or activity deadline. Initialization is outside the 120-second monitor activity budget.

Offline verification: all 55 detector tests pass, including startup ordering, 12-metric inference, threaded parity/error handling, cross-bucket walk-forward batching and failure propagation, batched density scoring, model concurrency, cache behavior, and wall-time budget expiry. Ruff and diff checks pass. Real sim-tower calls returned seven five-point series. Before overlap, setup/detect took 119.99/131.56 s; after overlap they took 129.16/147.11 s. Batching matching walk-forward fingerprints reduced the latest setup/detect to 99.15/62.12 s, under the 110-second target and worker's 120-second activity limit. The cause is still `uplink_down` for injected `heavy_user` (confidence 0.323); accuracy and repeated-run reliability remain unresolved.
