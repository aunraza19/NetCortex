# Detector decisions

- `run_engine()` remains independently testable with approved-shaped frames and an injected backend. Public `detect(site_id, window, history)` imports the actual core `MetricsWindow`, `DetectionResult`, `Cause`, forecast models, `Settings`, and `ModuleUnavailable`; `DetectorUnavailable` subclasses the shared error. It combines prior history with the current window, applies the window cutoff and site checks in the engine, and returns grouped core series without writing forecasts.
- Build one-minute snapshots from source rows at or before `as_of`, grouped by target role and interface role supplied as configuration. Without a role mapping, exact target/interface identifiers stay separate under `target:`/`interface:` feature names; the detector does not infer that a host is DNS or an interface is an uplink. Only RTT, jitter, loss, utilization, drops, and errors enter this feature path. DNS-kind probes use these standard core metrics directly when present; the simulator's supplemental DNS-resolution sidecar is unused. Subscriber traffic and backhaul quality are outside this feature model.
- Lags and rolling statistics shift by one minute; missing observations are never backfilled from the future. Rows for another site, invalid timestamps, and supplemental source rows are rejected. Probe and interface frames must each have a single, matching source when source metadata is supplied, preventing mixed live/simulator/RIPE measurements. Sparse history returns an explicit `insufficient_history` result with no cause.
- Cloud and local TabPFN adapters are lazy, optional integrations. They select TabPFN 3.5 and send explicit 0.1/0.5/0.9 regression quantiles. Cloud credentials come from an injected argument or `TABPFN_TOKEN`/`TABPFN_API_KEY`, are never logged, and client calls use a 30-second timeout. The local adapter uses `ModelVersion.V3_5`. The unsupervised extension is fit on varying raw normal TRAIN metrics only; constant metrics are excluded because they cannot define a continuous density. Its low log-likelihood is normalized by the empirical CDF of normal VALIDATION scores. Its random feature permutation is seeded consistently for reference and live scores, with the extension's module RNG restored after each call. Provider errors raise `DetectorUnavailable` and are never replaced by fixtures.
- Cause classifier fitting uses aligned feature vectors and labels from TRAIN case sidecars only; expected template metadata is never a feature. Gate 2 preparation writes a versioned data-only artifact from TRAIN and normal VALIDATION snapshots only. TEST is not enumerated or opened during preparation/configuration. Public `detect()` receives no labels; `configure_detector()` fits and caches the classifier and anomaly model from the validated artifact. Its at-most-three normal VALIDATION scores and fixed 0.7 cutoff establish plumbing only, not an accuracy or production-threshold claim. Fitted contexts use fingerprints; expanded forecast training is capped at 2,048 rows.
- Sustained forecast evidence is walk-forward: each of the last three contiguous minute observations is compared against a forecast made strictly earlier and targeting that exact minute. Forecast timestamps, horizon, finite quantiles, order, and physical bounds are validated. One excursion does not count as sustained. Missing, stale, or sparse input returns unavailable, not healthy.
- FixtureBackend exists only to exercise the offline pipeline. Its deterministic persistence bands and simple rules are identified in every result as fixture provenance and cannot support a TabPFN performance claim.
- Forecast output is returned in memory with model provenance. The detector does not write forecast rows; persistence belongs to the core worker. Cause/template parameter construction and CHR checks are outside this package.
- Explicit fixture provenance maps to core `mode="mock"` and `model="fixture_persistence"`; cloud and local provider identities retain their configured mode. Core `Settings()` supplies runtime configuration; SecretStr is unwrapped only when constructing the cloud provider. Tests instantiate Settings with `_env_file=None`.
- `prepare_detector(cases_dir, out)` reads only the `train/` and `validation/` packs, checks safe observation paths and split/seed/time boundaries, and writes feature data rather than SDK objects. `configure_detector(artifact, settings=None, backend_factory=None)` is explicit startup setup; missing/invalid artifacts and provider failures raise `ModuleUnavailable`, with no fixture substitution. The process cache is reusable across public detect calls and can be cleared explicitly.
