# Detector decisions

- Keep `run_engine()` independent from `netcortex_core`. Its inputs are the approved-shaped probe/interface frames, `site_id`, an aware UTC cutoff, an injected backend, and optional explicit training vectors. The core-facing `detect()` lazy-imports actual core symbols and fails clearly while their contract is unavailable; this avoids a copied Settings class or a guessed shared result schema.
- Build one-minute snapshots from source rows at or before `as_of`, grouped by target role and interface role supplied as configuration. Without a role mapping, exact target/interface identifiers stay separate under `target:`/`interface:` feature names; the detector does not infer that a host is DNS or an interface is an uplink. Only RTT, jitter, loss, utilization, drops, and errors enter this feature path. Supplemental DNS resolution, subscriber traffic, and backhaul quality rows remain experimental.
- Lags and rolling statistics shift by one minute; missing observations are never backfilled from the future. Rows for another site, invalid timestamps, and supplemental source rows are rejected. Probe and interface frames must each have a single, matching source when source metadata is supplied, preventing mixed live/simulator/RIPE measurements. Sparse history returns an explicit `insufficient_history` result with no cause.
- Cloud and local TabPFN adapters are lazy, optional integrations. They select TabPFN 3.5 and send explicit 0.1/0.5/0.9 regression quantiles. Cloud credentials come from an injected argument or `TABPFN_TOKEN`/`TABPFN_API_KEY`, are never logged, and client calls use a 30-second timeout. The local adapter uses `ModelVersion.V3_5`. The unsupervised extension is fit on normal TRAIN observations; its low log-likelihood is normalized by the empirical CDF of normal VALIDATION scores. Provider errors raise `DetectorUnavailable` and are never replaced by fixtures.
- Cause classifier fitting requires explicit aligned feature vectors and labels supplied by the caller. The evaluator builds those vectors from TRAIN case files only; validation labels select the threshold maximizing F1 under a false-alert budget computed from unioned normal detection-window exposure per site, consistent with the reported false-alert/site-day denominator. Positive cases and their event duration do not enlarge the budget. TEST is used only for scoring. Labels and expected template parameters are not feature columns. Fitted contexts use a fingerprint for cache keys; the expanded five-horizon training table is deterministically capped at 2,048 rows while retaining every horizon.
- Sustained forecast evidence is walk-forward: each of the last three contiguous minute observations is compared against a forecast made strictly earlier and targeting that exact minute. Forecast timestamps, horizon, finite quantiles, order, and physical bounds are validated. One excursion does not count as sustained. Missing, stale, or sparse input returns unavailable, not healthy.
- FixtureBackend exists only to exercise the offline pipeline. Its deterministic persistence bands and simple rules are identified in every result as fixture provenance and cannot support a TabPFN performance claim.
- Forecast output is returned in memory with model provenance. Database writes are not enabled: forecast writer ownership, conflict keys, and retry semantics are still open in Aun's contract request. Cause/template parameter construction and CHR checks are outside this package until their real contracts are available.
