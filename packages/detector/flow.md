# Detector flow and API

`build_features(probes, interfaces, *, site_id, as_of, target_roles=None, source_roles=None)` checks required columns, aware UTC cutoff, site isolation, timestamp validity, and source boundaries. If source fields are present, each frame must use one source and both frames must agree. It returns a one-minute-indexed pandas frame with past-only values, lags, rolling summaries, and UTC calendar fields. With no role mapping, target and interface IDs remain distinct under `target:` and `interface:` prefixes. `detect()` maps either default-prefixed or explicitly role-mapped raw feature names through the core `series_key()` helper, preserving colons in DNS target names. It raises `ValueError` for malformed or mixed-site inputs.

`run_engine(probes, interfaces, *, site_id, as_of, backend, history_start=None, config=None, training_features=None, training_labels=None, anomaly_threshold=None)` is the independently testable inference API. It returns a plain dictionary with anomaly/cause/forecast/evidence fields, status, provenance, and a supplemental-use flag. Missing, stale, or sparse observations return `availability="unavailable"` and a null anomaly outcome. Invalid backend causes and provider failures are errors (`DetectorUnavailable`), not healthy results. The backend is injected; this function does not silently choose a mock.

`prepare_detector(cases_dir, out)` reads `train/*.json` and `validation/*.json` only, checks case split, safe probe/interface paths, unique case IDs/seeds, and non-overlapping aware time bounds, then writes a versioned JSON feature artifact. TRAIN labels are kept aligned as supervised targets; normal TRAIN snapshots and up to three normal VALIDATION snapshots are stored separately. It never lists or reads `test/`. `configure_detector(artifact, *, settings=None, backend_factory=None)` validates the artifact, fits the cause classifier from TRAIN, fits the anomaly estimator only on varying raw normal TRAIN metrics (constant columns are excluded), scores the normal VALIDATION references, and caches the real cloud/local backend plus a fixed 0.7 plumbing threshold. It returns the configured backend; provider/setup failures are sanitized `ModuleUnavailable` errors. `clear_prepared_detector()` resets the process cache.

`detect(site_id, window, history)` accepts actual core `MetricsWindow` objects. It combines their probe/interface rows, runs the current window through `as_of`, and uses the explicitly prepared backend when configured. The prepared classifier reuses TRAIN labels, and anomaly scoring uses the cached normal reference. Without startup configuration it permits only an explicitly injected fixture backend for offline contract tests; a real provider is rejected before forecast or scoring calls. It maps in-memory forecasts to core `SeriesForecast`/`ForecastPoint` objects with canonical series keys, preserving DNS target colons; an unrecognized forecast metric fails explicitly instead of disappearing. Missing/stale measurements and provider failures raise `DetectorUnavailable`, a `ModuleUnavailable` subtype. It never writes forecast rows. Fixture backend output is marked `mode="mock"` and `model="fixture_persistence"`; startup preparation rejects fixture provenance.

`TabPFNBackend("cloud" | "local")` supplies real provider calls. Cloud uses `tabpfn_client`, `TABPFN_TOKEN`/`TABPFN_API_KEY` or an injected key, `set_access_token`, v3.5 factories, and a finite client timeout. Local uses TabPFN classifier/regressor and `ModelVersion.V3_5`. Regressors request `output_type="quantiles"` for quantiles `[0.1, 0.5, 0.9]`; the bands are sorted before reporting. The unsupervised extension is fit on normal TRAIN data; low log-likelihood is normalized against normal VALIDATION scores. Its extension-level random feature ordering is seeded identically for reference and live score calls, with the original RNG object restored afterward. Regressors use lag/calendar predictors and shifted targets; only raw RTT, loss, and utilization are forecast targets. Horizon-expanded fit rows are capped at 2,048 with deterministic per-horizon sampling. Quantile-first SDK responses are converted horizon-wise, and nonfinite, unordered, out-of-range, or invalid-time forecasts fail explicitly. Missing packages, key, model download, GPU/runtime support, and inference failures are explicit. No network request is made by the unit tests.

`FixtureBackend` is an explicit offline fixture only. Its provenance is embedded in outputs. It supplies deterministic persistence bands and simple visible rules to verify evaluator wiring, not product inference.

`python eval/run.py --mode mock|cloud|local [--cases eval/cases] [--out eval/results/detector.md] [--limit N]` runs the offline evaluator over split sidecars and probe/interface Parquet observations. It validates split separation and safe observation paths; TRAIN causes are classifier targets, VALIDATION calibrates evaluation thresholds, and TEST is scored only after setup. It records actual denominators and unavailable results in Markdown.
