# Simulator decisions

| Decision | Alternatives and tradeoff | Reason | Practical implication |
|---|---|---|---|
| Package as Python 3.12 `netcortex-simgen` with `netcortex_simgen` imports and `src/` layout. | Keep scripts inside `data/`; simpler but not importable by other packages. | The brief requires a CLI and Python API. | Install from `packages/simgen/`; root workspace and lockfile remain lead-owned. |
| Build samples from seeded NumPy arrays and return pandas frames. | Handwrite row values or use LLM-generated series. | Seeded arrays are repeatable, economical, and retain daily structure. | Same seed and start yield identical observations; values remain generated data, not real measurements. |
| Use 10-second probes, 30-second interfaces, and a Pakistan local-time weekday/weekend demand curve. | One cadence, UTC-shaped daily demand, or flat utilization. | Matches collection timing and evening traffic peaks. | UTC timestamps are stored; local time drives demand. One site/day has 8,640 ping times/target and 2,880 samples/interface. |
| Keep only the seven brief cause strings and their expected template IDs. | Add convenient aliases or invent more shared values. | Those identifiers belong to Aun's contract. | `CAUSES` and `TEMPLATES` are local constants; fixture labels are plain dicts, not Pydantic types. |
| Separate internal `inject_frames()` from the public `inject(...)->ScenarioLabel`. | Return a local dict that looks like the future shared result. | The merged core publishes the schemas and transactional insert helpers. | Offline scenario fixtures work; public injection returns the core ScenarioLabel and atomically writes observations with overlap protection. |
| Use core metric insert helpers for database load and replay. | Guess an `ON CONFLICT` key from the draft schema. | Metric tables have no unique replay key; append semantics preserve observations. | Mock load validates files; real load/replay writes source-tagged observations in bounded batches. |
| Discover RIPE probes/measurements at runtime with finite timeouts, capped pagination, cache, and request spacing. | Hardcode IDs or crawl without page limits. | Provider contents change; raw downloads must be bounded and traceable. | Fetched observations retain measurement/probe IDs; offline tests use no network. |
| Prefer exact target/hour calibration; allow an explicit, opt-in public-DNS reachability role proxy only for `1.1.1.1` and `8.8.8.8`. | Transfer by default, or apply a role baseline to gateway, upstream-hop, game-server, or DNS lookup measurements. | The brief asks for per-target-role baseline statistics and root DNS ping data is available, but its route is not proven equivalent to either configured resolver target. | `--target-role-map` plus `--allow-role-proxy` are both required. Exact target data wins. Transfer scope and uncertainty are stored in calibration and generation metadata; other targets keep illustrative defaults. |
| Compute role/hour RTT, jitter, and loss statistics only for exact targets in the supplied role map. | Let provider role labels silently authorize cross-target use. | Role aggregation should describe only operator-designated source observations. | The map is `data/ripe-target-roles.json`; its two root-DNS addresses are explicitly marked as reachability proxies. The proxy transfers only to unmatched public-DNS targets and never means DNS lookup latency. |
| Make mock calibration fail unless an explicit real observation fixture is bundled. | Run against made-up/mock samples when `--mock` is selected. | A calibration artifact should be traceable to measured data. | `simgen calibrate --mock` exits without writing; real calibration writes ignored `data/calibration.json` plus a committed measured coverage report. |
| Make interface effects agree with ping scenario windows. | Alter only ping RTT/loss while leaving utilization/counters normal. | A detector needs the physical metric evidence for the stated cause. | Congestion raises utilization/drops; total uplink loss zeros primary counters and shifts configured backup; interference raises backhaul counters. |
| Keep gateway healthy for outside-provider/congestion incidents, and model total loss as exactly 100% with unavailable RTT/jitter. | Apply the same queue delay to gateway, or emit noisy near-total loss with a valid RTT. | Those outputs contradict the incident descriptions and packet semantics. | Gateway is a local control; total loss is not mistaken for a slow successful response. |
| Store DNS lookup and subscriber evidence in the actual core metric schemas. | Add unsupported columns to core tables or infer them from ping RTT. | Merged core defines DNS ProbeMetric and SubscriberMetric. | Supplemental rows disclose synthetic provenance and pending contracts; they are excluded from database loads. |
| Put labels in per-case JSON sidecars, never in feature rows. | Add cause/template to the metric DataFrame for convenience. | That directly leaks the answer to a detector. | Eval scoring joins expected labels only after inference; each case is clipped at its `as_of`. |
| Generate balanced train, validation and held-out test packs with distinct seeds and calendar windows. | Split adjacent windows from one run or reuse training cases as test. | Event leakage gives optimistic scores. | `--n 80` means 80 test cases plus 80 each in train and validation, ten per class in every split. It produces no scores itself. |
| Ignore large Parquet and raw RIPE cache files in version control. | Commit generated case packs/raw API payloads. | These artifacts are reproducible or grow quickly. | Small YAML fixtures are committed; use `simgen generate` and `simgen eval-cases` to materialize data locally. |
